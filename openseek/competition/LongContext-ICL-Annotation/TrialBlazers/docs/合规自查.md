# 合规自查

## 模型与框架

- 大语言模型：`Qwen3-4B`
- 服务框架：`FlagScale` + vLLM OpenAI-compatible API
- 服务配置：`configs/llm_config.yaml`
- 推理入口：`run_full_inference.sh`

## 数据与文件范围

- 使用本目录 `input/` 中的官方输入数据副本。
- 不包含外部语料、外部知识库、外部标注数据或外部检索服务。
- 不包含候选快照、历史提交 zip、历史 final outputs 或人工答案。
- 不包含训练权重、LoRA、adapter 或 checkpoint。

## 推理策略

- Task1/3/4 默认使用 `solver_debug_loop`；可显式切换到 `longctx_manyshot`。
- Task2 默认使用 `legacy_router`，重新生成四路候选后由 `Qwen3-4B` 在候选之间选择。
- Task5/6/7 使用多候选生成与候选路由。
- Task8 使用 pass@k、静态检查、执行 smoke test 和 repair。

## 提交格式

最终 zip 应只包含以下 8 个根目录文件：

```text
openseek-1-v1.jsonl
openseek-2-v1.jsonl
openseek-3-v1.jsonl
openseek-4-v1.jsonl
openseek-5-v1.jsonl
openseek-6-v1.jsonl
openseek-7-v1.jsonl
openseek-8-v1.jsonl
```

格式检查命令：

```bash
python verify_submission.py \
  --submission-dir outputs/upload_ready_${STAMP} \
  --zip-path outputs/upload_ready_${STAMP}.zip
```
