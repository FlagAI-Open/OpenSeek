# 代码方案与复现步骤

本精简包只保留可重新推理的必要代码、服务脚本、环境文件和说明文档；不包含候选快照、历史输出、提交 zip、PDF/TeX 报告或模型权重。全部 LLM 调用均通过本地 `Qwen3-4B` 服务完成。

## 1. 代码入口

- `run_full_inference.sh`：全量推理主入口，串联 Task1-Task8 并生成上传 zip。
- `src/main.py`：Task1-Task8 基础推理入口。
- `src/method.py`：prompt 构造、长上下文示例选择、模型调用、输出解析和静态校验。
- `src/prepare_submission.py`：清洗 8 个任务 JSONL 并生成 zip。
- `make_submission.py`：从已有 JSONL 目录重新打包。
- `verify_submission.py`：检查提交目录和 zip 格式。

## 2. 分任务代码

- Task1/3/4：默认走 `solver_debug_loop`；可选 `TASK134_BRANCH=longctx_manyshot`，使用 `src/run_manyshot.py` 和 `src/run_task4_budget_ensemble.py`。
- Task2：本精简包已删除候选快照，默认走 `TASK2_BRANCH=legacy_router`，由 `src/task2_candidate_router.py` 对四路重新推理候选做路由。
- Task5：`src/task5_ab_labeler.py` 与 `src/task5_candidate_router.py` 生成并融合 sadness 候选。
- Task6：`src/task6_candidate_router.py` 融合 genre-aware Y/N 候选。
- Task7：`src/task7_reasoning_retrieval.py`、`src/task7_semantic_tag_retrieval.py`、`src/task7_candidate_router.py` 负责 reasoning bank、semantic MMR 检索和候选路由。
- Task8：`src/task8_pytorch_passk.py` 负责 pass@k 代码生成、静态检查、执行验证和 repair。

## 3. 环境准备

```bash
cd /path/to/competition_official_submission_package_20260520
pip install -r requirements.txt

export FLAGSCALE_MODEL_PATH=/path/to/models/Qwen3-4B
export API_BASE=http://127.0.0.1:2026
export PYTHON_BIN=python3
```

## 4. 启动服务

```bash
bash scripts/start_service.sh
curl http://127.0.0.1:2026/v1/models
```

停止服务：

```bash
bash scripts/stop_service.sh
```

## 5. 全量推理

```bash

FRESH_RUN=1 \
CLIENT_CONCURRENCY=2 \
ROUTER_MAX_WORKERS=4 \
```

## 7. 输出校验

```bash

  --submission-dir outputs/upload_ready_${STAMP} \
  --zip-path outputs/upload_ready_${STAMP}.zip
```
