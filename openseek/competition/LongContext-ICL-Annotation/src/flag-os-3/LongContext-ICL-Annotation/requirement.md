背景介绍
在大语言模型（Large Language Models，LLMs）时代，高质量标注数据已经成为驱动模型能力跃升的关键燃料。无论是预训练、微调、对齐还是领域适配，模型性能的上限往往由训练数据的规模、多样性与标注质量共同决定。然而，传统人工标注成本高昂、周期漫长，且难以覆盖复杂、长程语义任务，严重制约了 LLMs 在专业领域和长文本场景中的落地效率。
上下文学习（In-context Learning，ICL）作为一种无需模型参数更新的少样本学习范式，凭借其灵活性与即用性，已经在多种自然语言处理任务中展现出接近甚至超过微调模型的性能。通过在提示中嵌入“输入-输出”示例，LLMs 即可“理解”任务意图并泛化至新样本，极大降低了对标注数据的依赖。
然而，当前 ICL 研究主要聚焦于短上下文或中等长度输入，在超长上下文（如数万至数十万token）场景下，ICL 的有效性、稳定性与可扩展性仍缺乏系统探索。一方面，海量示例文本蕴含丰富的任务/领域信息，如何高效排列示例并组织模型指令，避免干扰、混淆或注意力稀释，成为亟待突破的技术瓶颈；另一方面，超长的上下文中蕴含丰富的结构化和非结构化信息，对模型的记忆、推理与关键信息提取能力提出更高要求，简单的单步 ICL 推理已难以胜任，必须结合具有多步推理和分析的策略，构建具备“感知-规划-执行”能力的协同标注框架。
本赛道旨在面向复杂、真实世界的超长文本场景，系统性探索 LLMs 在自动化数据标注任务中的能力边界与实现路径。通过引导参赛团队设计具备示例选择、上下文组织、多步推理与协同决策能力的长上下文 ICL 标注框架，推动模型在标注准确性、稳定性与可扩展性方面不断逼近乃至达到人类标注水平。比赛期望汇聚学术界与工业界的创新方案，形成可复现、可推广的技术范式与开源成果，为构建高质量、低成本、可持续演进的下一代智能数据引擎奠定坚实基础。

赛题综述
长上下文场景中LLM自动数据标注挑战赛基于Qwen3-4B大语言模型，采用上下文（In-context Learning, ICL）范式开展自动化数据标注任务研究。参赛团队必须使用组委会统一提供的数据集，围绕超长上下文场景设计有效的 ICL 标注方案，并在统一评测集上完成推理与评测。组委会将依据标准化评测结果，对参赛方案进行综合评估并确定最终排名。

2.1 赛题目标
本赛题以大语言模型（Large Language Models）为核心驱动力，面向超长上下文条件下的自动化数据标注问题，探索兼具效率与精度的新型技术范式。赛题重点聚焦以下三个关键科学与工程问题：
1. 在超长上下文场景下，如何设计有效的模型指令与提示策略，引导 LLM 稳定、高质量地完成数据标注任务？
2. 当可用标注示例数量显著超过模型上下文容量时，如何为待标注数据构造信息密集、结构合理的超长上下文输入？
3. 在自动多轮对话或持续交互场景中，如何高效利用超长上下文，实现一致性与可扩展性兼顾的数据标注？
2.2 赛题详情
● 参赛团队自主设计一套完整的LLM自动数据标注方案，并在统一的数据集与评测设置下进行实验验证。比赛将以标准化榜单形式公布各参赛方案的评测分数及排名。
● 除评测结果外，参赛团队还需按照赛事要求提交技术方案文档与可复现源代码。组委会将对提交方案进行复现验证，并对技术方案本身进行评审。最终成绩将由预测结果成绩与技术方案成绩加权计算得出，具体规则如下。
● 参赛队伍需按照赛题和赛制要求，提交技术方案和完整代码至Github OpenSeek官方开源项目下。
