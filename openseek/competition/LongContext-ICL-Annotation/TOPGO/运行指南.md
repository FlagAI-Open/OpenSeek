# TOPGO团队代码 - 容器环境运行指南

## 一、快速开始（容器环境）

### 1. 克隆代码
```bash
cd /home
git clone https://gitee.com/anbeime/topgo-openseek.git
cd topgo-openseek
```

### 2. 获取数据
```bash
# 方式一：从OpenSeek仓库获取数据
git clone https://github.com/FlagAI-Open/OpenSeek.git OpenSeek_temp --depth 1
mkdir -p data
cp -r OpenSeek_temp/openseek/competition/LongContext-ICL-Annotation/data/*.json data/
rm -rf OpenSeek_temp

# 方式二（如果GitHub无法访问）：设置代理或使用镜像
# export HF_ENDPOINT=https://hf-mirror.com
```

### 3. 安装依赖
```bash
# 基础依赖
pip install openai tqdm requests

# 如果需要离线加载Tokenizer（可选）
pip install transformers
```

### 4. 配置API
```bash
# 华为Ascend环境
export QWEN_API_BASE="http://localhost:9010/v1/"
export QWEN_API_KEY="EMPTY"
```

### 5. 运行任务
```bash
cd src

# 运行单个任务
python main.py --task_id 1 --device ascend

# 或运行所有任务
for i in {1..8}; do
    python main.py --task_id $i --device ascend
done
```

### 6. 查看结果
```bash
ls -lh ../outputs/
head -n 5 ../outputs/openseek-1-v1.jsonl
```

## 二、命令参数说明

```bash
python main.py \
    --task_id 1 \              # 任务ID (1-8)
    --max_input_length 10000 \ # 最大输入长度
    --log_path_prefix ../outputs/ \  # 输出路径
    --device ascend            # 设备类型: ascend/nvidia
```

## 四、常见问题

### Q: HuggingFace连接超时怎么办？
```bash
# 设置国内镜像
export HF_ENDPOINT=https://hf-mirror.com

# 或者在代码运行前执行
echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
source ~/.bashrc
```

**说明**: 代码已内置国内镜像支持，即使不设置也能正常运行（会跳过Tokenizer加载，使用字符估算模式）

### Q: 如何确认模型服务已启动？
```bash
# 测试API
curl http://localhost:9010/v1/models
```

### Q: 如何下载结果？
```bash
# 打包结果
zip -r results.zip outputs/
# 然后通过IDE文件管理器下载
```
